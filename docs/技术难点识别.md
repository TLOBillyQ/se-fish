# 技术难点识别

依据：`design/策划案--渔力全开.docx` v1.00 × SE 编辑器能力。能力结论来自 `editor-cli docs search`（manual / game-api，2026-09-18，CLI 0.18.0）与本地 `EggyAPI.lua`。docs 返回的条目均无版本号与 canonical URL，标"未查到"的项不等于"不支持"，需原型验证。

## 高风险：存在能力缺口或无法在试玩中验证

### 1. 非人形鱼 / 首领的模型与动画

- 需求：14 种精英鱼与首领全部非人形（鳗、蟹、三头鲨、翼龙、20 米哥斯拉），各有专属移动与攻击动作。
- 能力：自定义模型导入流程文档只有"导入角色（人形骨骼）"，导入时校验人形骨骼节点命名。`AnimatedUnit:PlayAnimation(animName)` 能播"模型自带动画片段或与骨骼匹配的动画资源"，服务端调用全端同步；但非人形带动画模型如何进图，文档未查到。
- 连带问题：`AnimatedUnit` 不带 Controller，没有 `Health` / `TakeDamage` / `MoveTo` / `Died`。鱼的血量、受击、移动、仇恨全部自研。
- 先验证：官方资产库里有无可用的带动画生物；非人形 FBX 能否导入成 `AnimatedUnit`。都不行则退到 `ModelUnit` 拼装 + Tween / Motor 程序动画，美术表现要相应降级。

### 2. 鱼的移动与 AI

- 能力：`PathfindingService`（`HasNavMesh` / `HasDynamicNavMesh` / `CreatePath{AgentRadius, AgentCanClimb}`）、`PathfindingLink`。
- 缺口：导航网格只解决地面行走。飞行（白头鹰、风神翼龙 20 m/s）、跃起落点 AOE、绕岛巡航后跃出咬人并叼走玩家（沧龙）、随机翻滚都要自写轨迹。"撞墙转 90°""触水即消失"需自写检测。
- 性能：逻辑帧 30 Hz，鱼由服务端逐帧驱动；8+ 玩家 × 每人多条上岸的鱼，需做数量上限与追踪降频。

### 3. 水体判定

- 需求：抛竿落点在不在水里；鱼逃到水里消失；空气墙挡游泳。
- 能力：API 中 Water 只出现在材质参数；`RaycastResult` 未见水体标识；`ControllerStateType.Swimming` 只针对角色自身。没有"某点是否在水中"的查询。
- 方案：每个钓鱼区配置水面高度 + 水域 `TriggerUnit`（或多边形数据），落点与鱼的位置自行判定。

### 4. 付费闭环（金豆 / 乐园币 / 广告 / 盲盒）

- 能力：`CommodityService`（`ShowGoodsPurchasePanel`、`SetGoodsPanelVisible`、`ConsumeCommodity`，事件 `GoodsPurchaseCompleted`、`CommodityObtain`）；`AdvertisementService:ShowRewardedVideoAd(player, goodsId, successEvent, failEvent, adTag)` 与 `PlayAdvertisementWithEvent`；邮件系统可发"游玩奖励"类商品。
- 难点：
  - `goodsId` 来自商业化后台配置，编辑器试玩内无法走真实支付；`MemoryStoreErrorCode.UnpublishedPlace` 表明部分云服务未发布不可用。需要一张已发布的测试图。
  - 购买事件标注为 `local` 触发，服务端发货要防伪造、防掉单。
  - "支付 / 看广告期间暂停复活倒计时，取消后恢复"：广告有 `failEvent`，购买面板的取消 / 失败回调未查到。
  - 盲盒用金豆还是金币在策划案里自相矛盾（见 `to-questionnaire-策划案内部矛盾.md`），决定它走商品系统还是纯 Lua。

### 5. 存档体积与可靠性

- 能力：`DataStoreService`（`GetDataStore` / `GetGlobalDataStore` / `GetOrderedDataStore`，`UpdateAsync` CAS，版本历史），全异步，须在 `Task:Spawn` 内调用；`game:BindToClose` 关服前留 30 秒。官方 fishing-demo 的做法：`pcall` 重试 + 会话锁 + 30 秒自动存档 + Attribute 同步客户端。
- 难点：
  - 物品不叠加，每条鱼获带个体倍率与烤制倍率；道具栏 8 + 背包 40 + 盲盒"不受背包上限"→ 单键体积无上界。`ValueTooLarge` 的具体字节数文档未给。需要紧凑编码，并给盲盒溢出设硬上限。
  - 限流错误码齐全（`ReadThrottle` / `WriteThrottle` / `KeyWriteThrottle` / 单服务器与全服务器速率），写入必须合并、排队。
  - 离线续存项多：所在钓鱼区与坐标、濒死 / 死亡标记、虚弱剩余时间、药水次数、图鉴最大重量、新手任务进度。

## 中风险：有能力，但实现量大或有坑

### 6. 全服纪录

可行。`OrderedDataStore:GetSortedAsync` 即排行榜用途，或 Global DataStore + `UpdateAsync`。问卷里"未找到跨房间共享数据接口"的判断已过时，应更新。难点在约 100 种鱼的键设计、写限流，以及跨服务器刷新（`MessageService:PublishAsync`，单条 ≤ 1 KB，尽力而为不保证送达）。

### 7. 玩家状态改造

- 濒死锁血：原生 `Health` 归零即触发 `Died`。300 点血、锁 1 血、无敌、15 秒抢救都要自管血量，原生血条用 `CoreGuiType.Health` 关掉。
- PK 区 / 安全区 / 小队免伤：未查到原生友伤开关，`Camp` 是出生点绑定的静态阵营，不适合运行时 3 人小队。伤害统一走服务端判定。
- 变大药水：`HumanUnit:SetScale` 有；`EggyUnit` 上是否可用需验证。吃满 10 个是 3 倍体型，影响碰撞、相机、头顶挂点、举鱼位置。
- 风神之翼：`GravityEnabled = false` + `ApplyForce`，自写 20 米限高与缓降。
- 哥斯拉变身：`EggyAppearance:SetAppearanceByAssetId` 只接生物预设；自定义外观走 `CustomAppearanceService`，须在服务端执行才全端可见。

### 8. 举鱼

原生 `EggyController:Lift` 的目标只能是 `EggyUnit`，且文档明说 `OnLiftBegin` 在当前运行包可能不触发，不能作为业务入口。改用头顶 `Attachment` 跟随；团队知识提示运行时 `WeldConstraint` 无动态连接属性，需验证 `RigidConstraint` 或每帧 `PivotTo`。

### 9. 高频输入

冲锋枪 0.1 秒连发、收线狂点，都是每人每秒约 10 次 RemoteEvent。RemoteEvent 的频率与包大小上限文档未查到，每次只能带一个 payload。客户端按时间窗聚合，服务端用 `World:GetServerTime()` 校验 CD 与次数上限，命中用服务端 `PhysicsService:Raycast`（目标须 `CanQuery` 且碰撞组允许）。

### 10. 摆渡

`SeatUnit` / `Seated` 状态存在；"站在船上被带走"依赖物理摩擦，不可靠。建议倒计时结束时把船上 Trigger 内的玩家直接传送，船只做表现。`TeleportService:TeleportAsync(mapId, players)` 是跨地图传送，可作"七区拆成多张图"的退路，但会拆散同房玩家，搭便船与返程的语义要重做。

### 11. 单图七区的规模

地图容量、单位数量上限文档未查到（只查到图片 ≤ 3 MB、1920×1080）。常驻房间里"丢弃物永不消失"是无界增长，必须加总量上限与回收。场景用 `IsStaticOptimization`，注意标记后脚本查不到该单位。

### 12. 常驻房间

世界模式模板支持；2026.8.20 更新后编辑器多人试玩支持随进随出。房间人数上限未查到（API 无 `MaxPlayers`），"8 人以上"需向平台确认。

## 低风险：有直接对应能力

| 需求 | 能力 |
|---|---|
| 鱼线 | `LinkEffectUnit.EndPosition` + 官方特效 5379"连线-绳子"，客户端逐帧更新终点 |
| 头顶文字泡、NPC 交互 | `SceneGui` 把 EUI 节点挂到单位插槽；无 ProximityPrompt，距离检测自写 |
| 血量球 / 饥饿球 | `EUIProgressTimer` 环形进度 |
| 背包拖拽 | `EUINodeBase` 的 `OnTouchMoved` 等触摸事件自实现拖放 |
| 隐藏原生按钮（举起、滚动、背包、血条） | `CoreGuiType` |
| 通关成就 | `ArchiveService:SetAchievementProgress` / `AchievementComplete` |
| 开场对话 | 剧情对话编辑器 / `StoryService` |
| 鱼、武器手持挂接 | 人形骨骼"挂接模型"、`Attachment` |

原生 `Backpack` / `Tool` 类存在，但"不叠加 + 个体倍率 + 拖拽 + 双栏"与其模型不符，物品系统建议自研。

## 文档未查到的事项

`docs search` 与 `EggyAPI.lua` 都没有给出答案，不等于不支持。按确认途径分组。

| 事项 | 影响 | 查过的关键词 |
|---|---|---|
| 世界模式房间人数上限 | "8 人以上同时在线"能否成立（§12） | 房间人数上限、最大人数；API 无 `MaxPlayers` |
