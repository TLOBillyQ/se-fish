| 项目 | 值 |
|------|----|
| 游戏名 | 《钓鱼这么危险啊喂！》（对外名《渔力全开》） |
| 地图类型 | 蛋仔派对 SE 世界地图 |
| 同时在线 | 8 人以上，随时可进出 |
| PK 模式 | 开启杀戮模式；第一关全员免伤不能 PK，其余关卡非组队玩家可互相 PK |
| 核心循环 | 捡/买鱼饵 → 钓鱼 → 杀鱼 → 卖鱼/抽奖 → 买更好装备 → 解锁下一关 |

## 2. 玩家属性

| 属性 | 基础值 | 上限 | 备注 |
|------|--------|------|------|
| 血量 | 300 | 600 | 每吃 1 个变大药水 +20%，最多 10 个 |
| 饥饿度 | 300 | 300 | 每秒 -1；降到 0 后每秒 -5 血量，提示"我要饿死了！" |
| 移动速度 | 基础值 | 基础 x 3.0 | 每吃 1 个加速药水 +10%，最多 20 个 |
| 体积 | 基础 | 基础 x 3.0 | 每吃 1 个变大药水 +20%，最多 10 个 |

加速药水超限提示：你的速度已经达到最大，还是把它送给其他伙伴吧。
变大药水超限提示：你的身体和血量已经达到最大，还是把它送给其他伙伴吧。

## 3. UI 布局

### 3.1 顶部

左上角：分享任务按钮、血量球、饥饿球。右上角：图鉴、商店、盲盒三个按钮。

### 3.2 底部装备栏

| 位置 | 说明 |
|------|------|
| 最左（武器栏） | 点击打开武器切换弹窗；选中后武器拿在右手 |
| 中间（道具栏，2-8 格） | 起始 2 格，升级 6 次达上限 8 格；道具不叠加；满了无法拾取钓竿/食物，但仍可拾取武器/鱼饵 |
| 最右（鱼饵栏） | 点击打开鱼饵切换弹窗；弹窗列出背包里现有鱼饵 |
| 右侧（背包按钮） | 展开背包（5-40 格）和道具栏；可拖拽调整；背包中的鱼/钓竿无法直接使用，须拖入道具栏 |

注（已确认）：道具栏起始 2 格，6 级升级（2+6=8）。商店表编号 27（背包升级 7，6400 金）作废，实际只开放升级 1-6。

## 4. 钓鱼系统

### 4.1 流程

1. 选中鱼竿，2 号位显示"抛竿"
2. 点"抛竿"，由服务端确认落点与可钓水域
   - 落点不在可钓水域：显示短暂红色落点和失败原因，不消耗鱼饵，立即恢复可抛竿
   - 落点在可钓水域：消耗本次选用的鱼饵，显示浮漂和等待提示，约 3 秒后抽取上钩的鱼；本次未抽到鱼则结束等待、提示重新抛竿，不退回已用鱼饵
   - 抛竿前置条件不满足：按具体原因给出短提示，不进入等待；关闭界面或重新打开不会重播失败提示
3. 上钩后需给玩家提示（音效/文字/按钮高亮，具体形式待定）
4. 左边出现钓鱼进度条，初始 50%；每秒自动 -5%；每次点"收线"按钮 +5%
   - 只有"收线"按钮可触发加 5%，点进度条无效（已确认）
5. 进度降至 0：脱钩，按"收线"收竿
6. 进度达到 100%：播放收线动画，鱼顶在头上；按钮变"放下"
7. 点"放下"：鱼落地，按品级行动

注（已确认）：收线难度全局统一，不按鱼区分；被其他界面遮住时进度继续下降，不暂停，不直接判脱钩。

### 4.2 上钩条件

- 所在钓鱼区匹配 AND 鱼竿等级 >= 配置值
- 鱼饵列 = 0：任何鱼饵都能钓到（已确认）
- 无合适鱼饵/鱼竿时，按"无饵 + 1 级竿"降级筛选（保证每区有保底鱼）
- 按权重随机抽取 1 条上钩

### 4.3 随机参数

```
随机值 = random(0, 100)
倍率   = 1 + 随机值 / 100          -- 范围 [1.00, 2.00]
重量   = 基础重量 x 倍率（精确到小数点后 2 位）
卖出价 = 基础出售价格 x 倍率
烤熟价 = 基础出售价格 x 倍率 x 1.5
```

### 4.4 鱼上岸后行为

| 类型 | 行为 |
|------|------|
| 普通/极品 | 随机方向逃跑；每 3 秒转 90°；碰到水消失 |
| 精英 | 主动攻击玩家；逃跑条走完后直线逃入水消失 |
| 首领 | 同精英，更高血量/伤害 |

## 8. NPC 系统

### 8.1 钓鱼佬（收购 NPC）

- 分布：每个钓鱼区各一个
- 功能：回收玩家背包中的鱼获与多余道具，按物品表金币价值列结算
- 商店只卖不买，出售动作统一走钓鱼佬，不走商店
- 信物兑换（已确认）：喂精英信物 → 首领饵 ×1；喂首领信物 → 船票 ×1；均 1:1，满格时拒绝且不消耗物品

### 8.2 钓场老板（商店 NPC）

- 分布：地图中央商店区
- 功能：售卖鱼竿、鱼饵、武器；道具栏升级
- 货币：金币

### 8.3 摆渡 NPC

- 分布：各钓鱼区入口
- 摆渡是钓鱼区之间唯一的通行方式（已确认细则）：
  - **去程**：乘船者中一人交出 1 张船票，倒计时后带走载具上所有玩家；无票同行者为搭便船，合法
  - **返程**：按人付金币，立即出发
  - 船票为过关道具，不绑定个人，可掉落、可拾取、可转赠

## 9. 组队系统

- 支持组队（队伍规模待定）
- 队友共享视野，可在同一钓鱼区协作
- 对抗模式：8 人以上在线时启动杀戮模式，队伍间可 PVP
- 组队不影响各自独立的钓鱼进度与背包

## 10. 烧烤系统

- 击杀直接获得普通/极品鱼获（已确认）：极品鱼获可直接投入抽奖机，无需先加工
- 烧烤是可选的后续加工：玩家可在烧烤点将鱼获加工为烤鱼，价格与恢复量更高，但烤后不能再投入抽奖机
- 烤过头则烤糊：鱼获损毁并炸伤周围玩家
- 烧烤点自第三个钓鱼区起出现
- 烧烤配方与产出比例由物品表定义（每种食材 → 烤鱼名称、数量）

## 11. 死亡与复活

- HP 归零后进入死亡状态
- 复活方式（待定）：原地等待倒计时 / 消耗自救道具 / 队友救援
- 死亡后背包与装备状态保留（不掉落），钓鱼进度保留
- 饥饿度持续消耗，降为 0 后每秒扣 5 HP（已在 MVP 代码与原案证实）
