## 钓鱼判定与鱼饵

### 吃鱼饵和挂鱼饵是同一份库存

问：装在鱼饵栏钓鱼，与在道具栏选中后点 2 号位「吃」回血回饥饿度，是不是同一份鱼饵？

结论：**同一份。** 吃一个少一个，玩家可能把自己吃成没饵可钓。

### 钓鱼表里多出的那串鱼饵名是旧稿

问：钓鱼表里那串鱼饵名（蚯蚓 / 贻贝 / 生蚝 / 蚂蟥 / 椰子 / 小海龟）是什么？其中「贻贝」「生蚝」在物品表里没有条目。

结论：**旧稿，删掉。** 钓鱼表里那串鱼饵名去掉，贻贝、生蚝不进物品表。

## 收线

### 加 5% 只由「收线」按钮触发

问：正文写「每次点击进度条加5%」，按钮叫「收线」，开场引导写「咬钩后狂点收线」——加 5% 到底是点哪里？

结论：**只有「收线」按钮可点。** 进度条只作显示。

### 收线难度不按鱼区分

问：正文只有一套全局数值（初始 50%、每秒 −5%、点击 +5%），钓鱼表也没有难度列，要不要按鱼分难度？

结论：**保持现状。** 所有鱼共用这一套数值，钓鱼表不加难度列。

### 鱼上钩要提示

问：抛竿落水 3 秒后上钩，正文没有任何提示；玩家不点就白丢一次（进度 50% 按每秒 −5% 掉到 0）。

结论：**要提示。** 提示形式和时长还没定，定了补在这条下面。

> 待补：音效 / 文字 / 按钮高亮用哪种，持续多久。

### 收线时被别的界面盖住：进度继续下降

问：收线过程中玩家打开商店、背包、图鉴，把收线界面盖住又不关掉，进度怎么算？

结论：**继续下降，到 0 脱钩。** 不暂停，也不因为开界面直接判脱钩。
